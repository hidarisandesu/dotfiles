# dotfiles リポジトリの運用ルール

セットアップと運用の手順は .claude/WORKFLOW.md を参照。

## 公開リポジトリである
誰でも内容と履歴を読める。トークン・鍵・個人や職場の情報など、公開できないものを絶対にコミットしない。一度プッシュした内容は履歴から消せない前提で扱う。

## このリポジトリが正本である
複数マシンで設定を同一に保つため、リポジトリ → ホームディレクトリの一方向フローを維持する。
設定を変更するときは、ホーム側（~/.claude/ や ~/.gitconfig）ではなく必ず正本（home/ 配下）を編集する。ホーム側を直接編集すると正本と実体が乖離する。

## リモートとの同期は sync-dotfiles スキルを必ず使う
ローカル変更の push、リモート変更の pull、双方向差分の rebase を状態に応じて実行し、正本・リモート・ホームの一貫性を保証する。
手動でバラバラに実行すると手順漏れで乖離が起きる。

## パスは相対パスで指定する
権限設定がプロジェクトルート基準で動作するため。
